The warnings are the point of this page. A row with a healthy count and no warnings is less informative than one saying "no held-out split". Two configurations this project measured won on a tuning split and lost on the held-out set -- k=31 in the injection experiment, and semantic entailment in the reasoning experiment. Both were caught only because the splits were separate.

Splits are represented two ways in this repository -- a split field inside the file, and sibling files (reasoning_cases.json / reasoning_cases_dev.json). Both are recognised, and a dataset whose held-out half lives elsewhere says so in its Splits column. Only the explicit _dev/_test/_validation/_train suffixes count: baseline_vs_controlplane_cases_v2 is a version increment, not a split, and crediting it as one would manufacture a healthy signal where none exists.
