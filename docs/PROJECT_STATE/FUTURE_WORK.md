## Deferred / Out of Scope for Now

- Real human annotation of the 270 annotation cases (`docs/DATA/DATASET_GAPS.md`).
- Real LLM response generation against the query-profile dataset (the *mechanism* now exists — `model_invocations` — but nothing has run the actual 270-record dataset through it yet).
- External dataset integration ("Person A" track — `docs/DATA/DATASET_REGISTRY.md`'s external-candidates table is still empty).
- Reconciling every remaining terminology variant across `docs/architecture/` and `docs/specs/` beyond what `CONTROLPLANE_FINAL_ARCHITECTURE_IMPLEMENTATION_MASTER_SPEC.md` §64 already covers (`BLOCKERS.md` B3).
- Fine-tuning any component (explicitly deferred by every relevant doc until a baseline shows a measured, specific weakness).
- Transcribing the remaining pages of the original competition brief (`BLOCKERS.md` B7).
- Model routing across multiple *providers* (Layer 10's remaining scope — FAST/STRONG roles exist, both still resolve to Groq).
- A local generative model pool (Qwen3 ~1.3B/4B, `docs/architecture/MODEL_AND_EVALUATION_DECISIONS.md`) — deferred again in Milestone 3 as a separately-scoped subsystem, see `docs/PROJECT_STATE/DECISIONS.md`.
- Cascading / confidence-aware adaptive compute (`docs/specs/CONTROLPLANE_ROUTING_SYSTEM_SPEC.md` §29-33, P1) — Model Router V0 is a single-shot threshold decision, no probe-then-escalate loop yet.
- Redis Streams-backed event transport (currently in-process; `EventTransport` interface is ready for the swap).
- Live Groq-vs-local classification comparison, and any live FAST-vs-STRONG Groq benchmark (harnesses exist; both need a `GROQ_API_KEY` supplied in-session to actually execute).
- Reworking Query Profiler complexity classification (still weak, though the hybrid baseline improved to 50.0% in Milestone 3's re-measurement — see `docs/EVALUATION/QUERY_PROFILER_RESULTS.md` and its reproducibility note).
- Reworking Risk Profiler's sensitivity-classification weakness (drives the newly-discovered `QP-198` false positive — see `docs/EVALUATION/RISK_PROFILER_RESULTS.md`); the governance/decision-support blind spot that caused the `QP-190` miss was fixed in Milestone 3.
- Pinning exact `torch`/`sentence-transformers`/`huggingface_hub` versions (or caching exemplar embeddings to disk) to fix the cross-session reproducibility gap found in Milestone 3 (`BLOCKERS.md` B9).
- Re-downloading the local embedding model with `allow_patterns` restricted to the PyTorch/safetensors files only (the current cache includes unused ONNX/OpenVINO/TF variants from `snapshot_download`'s default behavior — a minor disk-space inefficiency, not a functional issue).
- Real SQL/RAG/WEB/CHAT_HISTORY/MEMORY/AGENT capability implementations (Layer 5/11/18) — the Execution Graph and Capability Router already route to these node types, but every one of them executes via an explicit `MOCKED` handler today.
- Plan/plan_version concept and live (rather than after-the-fact) per-node `ROUTE_STARTED`/`ROUTE_COMPLETED` events — both deferred to whichever future milestone needs replanning or real-time observability, see `docs/PROJECT_STATE/DECISIONS.md`.
